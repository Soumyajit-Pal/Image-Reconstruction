Native PyTorch requires looping over all 225 spatial shifts individually, launching hundreds of small CUDA kernels with substantial driver launch overhead. Our custom kernel fuses all shifts into a single grid launch.

💻 Fused Kernel Implementation (`aggregation.cu`)

csrc/aggregation.cu CUDA C++ 
template <typename scalar_t>
__global__ void generate_shifts_kernel(
    const scalar_t* __restrict__ input,
    scalar_t* __restrict__ output,
    const int* __restrict__ dy_shifts,
    const int* __restrict__ dx_shifts,
    int num_shifts, int B, int C, int H, int W) {

  // Fused 1D indexing across (num_shifts * B * C * H * W)
  const int idx = blockIdx.x * blockDim.x + threadIdx.x;
  if (idx >= total_elements) return;

  // Direct cyclic shift calculation without Python overhead
  int src_h = (h - dy + H) % H;
  int src_w = (w - dx + W) % W;
  output[idx] = input[b * CHW + c * HW + src_h * W + src_w];
}
